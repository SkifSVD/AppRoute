# Изменения

Версии — по тегам выпусков `vX.Y.Z` (см. README, «Версии и выпуски»).

## [Не выпущено]

### Добавлено
- Версия по тегам git: ресурс версии во всех exe/dll, `--version` у утилит, версия в меню
  значка окна правил и в журналах службы и hook-DLL; `build.ps1 -Publish/-Zip/-Version`,
  тег выпуска (#63).
- Установщик `AppRoute-<версия>-setup.exe`: установка для текущего пользователя без прав
  администратора, обновление поверх с двумя резервными копиями, откат, удаление через
  «Приложения», тихий режим; обновление и удаление службы AppRoute с запросом UAC;
  `build.ps1 -Installer` (#64).
- Журнал hook-DLL для программ, запущенных из окна, с ярлыков и при входе в Windows:
  `%LOCALAPPDATA%\AppRoute\logs\<программа>.log`, пункт «Журналы запусков» в меню значка;
  дата во времени журналов hook-DLL и менеджера маршрутов (#68).
- Если файла AppRoute нет (например, его убрал в карантин антивирус), окно правил и запуск по
  правилу говорят, какого файла нет и что делать, вместо системной ошибки (#72).

### Исправлено
- Запуск по правилу программы, уже открытой без AppRoute, молча не действовал (окно открывалось
  в работающей копии): теперь окно, ярлык, автозапуск и approute-run предупреждают об этом (#70).

## 0.1.0 — первая версия

- Маршрутизация трафика выбранных программ через выбранный интерфейс или SOCKS5-прокси
  (hook-DLL, 32- и 64-битные программы, приложения Microsoft Store/MSIX).
- Окно правил `approute-gui`, ярлыки запуска, автозапуск программ при входе в Windows.
- Утилиты `approute-run`, `approute-config`, `approute-dns`, `approute-routes`; служба менеджера
  маршрутов.
- Драйвер WFP `approute-wfp.sys` (тестовая подпись; пакет для подписи Microsoft).
